# Implementation and Launch Checklist

## Before code

- [ ] Scope, PDS, copy, Figma, and assets approved.
- [ ] CMS models and content ownership named.
- [ ] CMS/email/analytics credentials stored outside Git.

## Before merge

- [ ] Visual comparison at 1440, 1024, and 390.
- [ ] Keyboard and focus path tested.
- [ ] Reduced motion, image alt text, errors, and empty states reviewed.
- [ ] Forms, links, metadata, robots/sitemap, and social previews checked.

## Before launch

- [ ] Domain, HTTPS, redirects, backups, consent, analytics, and rollback plan confirmed.
- [ ] Client signs launch approval.
