# Content Model Baseline

## Project

`title`, `slug`, `industry`, `category`, `year`, `status`, `thumbnail`, `coverImage`, `gallery`, `overview`, `challenge`, `solution`, `results`, `stack`, `publishedAt`, `featured`.

## Journal

`title`, `slug`, `cover`, `category`, `readingTime`, `author`, `content`, `publishedAt`.

Keep drafts distinct from published material. Public claims and results require client approval.
